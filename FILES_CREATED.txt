CONFIGURATION MODES
================================================================================

1. EMAIL_PROCESSING_MODE = "polling" (Default)
   - Background worker checks IMAP every 60 seconds
   - No setup required
   - 60-second average delay
   - Good for: Development and testing

2. EMAIL_PROCESSING_MODE = "webhook"
   - Real-time webhook processing
   - No polling
   - < 100ms response time
   - Requires email service setup (SendGrid/Mailgun)
   - Good for: Production

3. EMAIL_PROCESSING_MODE = "both"
   - Webhook primary, polling fallback
   - Maximum reliability
   - Works even if webhook fails
   - Good for: Critical systems


QUICK START
================================================================================

LOCAL DEVELOPMENT:
1. Set EMAIL_PROCESSING_MODE=polling (in .env)
2. Start backend: python -m uvicorn app.main:app --reload
3. Start listener: python scripts/imap_idle_listener.py
4. Send test RFQ via chat
5. Watch instant email processing!

PRODUCTION (SendGrid):
1. Set up SendGrid Inbound Parse webhook
2. Set EMAIL_PROCESSING_MODE=webhook (in .env)
3. Update WEBHOOK_TOKEN (in .env)
4. Restart backend
5. Test with real emails!

PRODUCTION (Mailgun):
1. Set up Mailgun route
2. Set EMAIL_PROCESSING_MODE=webhook (in .env)
3. Update WEBHOOK_TOKEN (in .env)
4. Restart backend
5. Test with real emails!
